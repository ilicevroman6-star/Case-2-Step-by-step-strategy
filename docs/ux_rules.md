# UX-правила игры · «Монополия на льду»

Единый свод правил интерактива. Каждое правило привязано к экрану (S01–S19) и к правилам из PDF.

## Основные правила (по ТЗ)

| # | Правило | Реализация в UI | Экран |
|---|---|---|---|
| 1 | **Кнопка неактивна (серая), если не хватает ресурсов** | Disabled: фон `#1B2F55`, текст `#7C8CA8`, курсор default, без тени. Примеры: «Купить · 12» при деньгах < 12; «Совершить трансфер» без выбранного ресурса; выбор ресурса у соперника, которого нельзя отнять больше, чем есть | S06, S14, S15 |
| 2 | **Событие показывается модальным окном и требует нажатия «Продолжить»** | Затемнение поля `rgba(7,13,26,0.74)`, модалка по центру, закрытие только кнопкой («Понятно», «Продолжить», «Применить эффект»). Click outside **не** закрывает. Авто-таймера нет | S06–S16 |
| 3 | **После действия — переход к следующему игроку с задержкой 1.5 сек** | После подтверждения модалка закрывается → тост «Ход переходит к игроку N» → 1500 мс → подсветка HUD следующего игрока (Dissolve) | все действия |
| 4 | **Выносливость ≤ 0 — экстренные сборы** | Пропуск следующего хода + восстановление до 10. Принудительное модальное окно до начала хода | S16 |
| 5 | **Репутация = 0 — игрок выбывает** | Если после события репутация стала ≤ 0: показ S17 (банкротство/выбытие), фишка снята, арены остаются заложенными | S17 |
| 6 | **Престиж ≥ 30 — победа после конца круга** | При достижении 30 в HUD появляется плашка «Цель достигнута — круг доигрывается». Победа объявляется только после того, как все игроки завершили круг | S18 → S19 |
| 7 | **Глобальное событие круга показывается при пересечении Старта** | Лидер пересёк СТАРТ (не первый круг) → бросок «монетки» 50/50 → модалка с ключом +/− и событием E1–E10; условие становится законом круга | S10 |
| 8 | **Текущий закон круга отображается в углу экрана** | Чип в верхней панели: `ЗАКОН КРУГА · E4 · Рента ×2` (красный фон `rgba(228,57,59,.12)`, рамка `#E4393B`), виден на всех экранах игры | S04–S19 |
| 9 | **Нечем платить — обмен или залог, иначе банкротство** | При нехватке ресурсов на платеж: всплывает предложение «Обмен (S15)» или «Заложить за ½ (вернётся 6)». Не помогло → S17: выход из игры, имущество заложено (рента не берётся), выкуп за полную цену | S15 → S17 |

## Дополнительные правила

| # | Правило | Реализация |
|---|---|---|
| 10 | Первый ход | Все бросают кости; при равных — повторный бросок, пока не выпадет большее (подсветка ничьих, кнопка «Повторить бросок») | S05 |
| 11 | Рента | Базовая 4; при законе E4 (отрицательном) — ×2 = 8. Показывается явно «4 → 8» | S06 |
| 12 | Залог / выкуп | Залог арены = 6 (полцены). Выкуп заложенной арены — только за полную цену 12 | S06, S17 |
| 13 | Обмен | Только в начале/конце хода; нельзя менять репутацию; сделка действует после подтверждения ОБЕИХ сторон (два статус-чека в центре) | S15 |
| 14 | Матч | Соперник — случайный из оставшихся; шанс = выносливостьᵢ / Σвыносливостей; отрицательная выносливость после матча → 0 и пропуск хода | S07 |
| 15 | Медиа | Репутация −3…+3, пол не опускается ниже 0 («минуса не может быть ниже 0»); закон E10 (позитив) ограничивает диапазон 0…+3, (негатив) удваивает эффекты | S08 |
| 16 | Random | Карточка только для наступившего; колоды A (позитив) / B (негатив); эффект применяется кнопкой «Применить эффект» | S09 |
| 17 | Допинг-контроль | Явный выбор из двух вариантов (честная / тёмная); без варианта «пропустить». Закон E6 меняет цены — подпись внизу модалки | S12 |
| 18 | Громкий трансфер | Нельзя отнять больше, чем есть у соперника — превышающие варианты disabled с помехой «у Игрока N есть X» | S14 |
| 19 | Пауза | Time Out — ход без потерь; кнопки «Завершить ход» и «Пропустить паузу» | S13 |
| 20 | Банкрот | Выбывший игрок: фишка снята, арены «заложены» (клик по клетке не даёт ренты), выкуп — полная цена | S17 |
| 21 | Пересчёт престижа | Автоматически в конце каждого хода; таблица с раскладкой формулы показывается после хода лидера и по кнопке «Престиж» | S18 |
| 22 | Лог событий | Последние 6 записей всегда доступны в правой панели поля; каждая запись — цветом игрока | S04 |

## Состояния кнопок

| Состояние | Визуал | Когда |
|---|---|---|
| Active | `#4FB8F0` / текст `#0A1428` | Действие доступно |
| Disabled | `#1B2F55` / текст `#7C8CA8` | Не хватает ресурсов / не сделан выбор |
| Danger | `#E4393B` / текст `#FFFFFF` | Банкротство, тёмная проверка, «Покинуть игру» |
| Success | `#2FB56B` / текст `#04260F` | Подтверждение, «Продолжить ход» |
| Loading | пульс 0.8 opacity | Рандом события/бросок (≤ 1 сек) |
