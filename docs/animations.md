## Тайминг-гайд (для разработчика)

| Контекст | Минимум | Рекомендуется | Максимум |
|---|---|---|---|
| Модалка (fade in/out) | 200 мс | **300 мс** | 500 мс |
| Переход между экранами | 250 мс | **300–400 мс** | 600 мс |
| Задержка перед следующим игроком | — | **1500 мс** | 2000 мс |
| Бросок кубика | 800 мс | **1000 мс** | 1500 мс |
| Шаг фишки | 300 мс | **400 мс** | 500 мс |
| Всплывающая цифра | 500 мс | **600 мс** | 800 мс |

## Типы кривых (применение)

| Кривая | Где применять | CSS-эквивалент |
|---|---|---|
| Ease out | появление модалок, цифр, кнопок | `cubic-bezier(0.16, 1, 0.3, 1)` / `ease-out` |
| Ease in out | переходы хода, движение фишки, прогресс-бары | `cubic-bezier(0.65, 0, 0.35, 1)` / `ease-in-out` |
| Linear | вращение костей/монеты, гравитация конфетти | `linear` |
| Spring (overshoot) | карточки событий, пружинка фишки | Figma Spring 60 % / 300 мс |

> Доступность: уважайте `prefers-reduced-motion` — при включённом режиме все длительности сокращаются до 100 мс (только fade), движение фишки — мгновенный телепорт.
