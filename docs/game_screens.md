# Игровые экраны · «Монополия на льду» (S01–S19)

## Связи экранов (базовая цепочка)

```
S01 → S02 → S05 → S04 ⇄ (S06…S16 — модалки поверх поля)
S04 → S10 (при пересечении СТАРТа) → S04
S04 → S15 (обмен) → S04
S04 → S18 (конец хода) → S04
S16 / S17 → S04 (ход пропущен) или выход
S18 → S19 (условие победы выполнено)
S19 → S01 / S02
```
